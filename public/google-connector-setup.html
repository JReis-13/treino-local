Connect your Google Sheet

Install a small Apps Script in a copy of your workout Sheet first. You do not need a Google Cloud project, OAuth consent screen, or Picker API.

  1. In the Sheet copy, open Extensions → Apps Script. Replace the starter code with the complete WorkoutConnector.gs source and save.
  2. Run initializeConnector in the Apps Script editor and approve Google’s prompt for your own script. In Project Settings → Script Properties, copy the WORKOUT_CONNECTOR_KEY value privately.
  3. Choose Deploy → New deployment → Web app. Select Execute as: Me and Who has access: Anyone. Copy the deployment URL ending in /exec.
  4. Back in Training plans, paste the URL and key. Choose Test connection, then Import training. Review the summary before using the plan.
  5. On Source, choose Validate source and Enable sync to allow date updates. Your workout is saved on this device before any sync attempt.
The URL alone does not authorize access; keep the connection key private. The connector can write only one available date cell in E5:E16 on a named TREINO workout tab. Test writes with a disposable Sheet copy.

Reconnect or revoke

If you lose the key on this device, paste it again in Training plans. Run rotateConnectorKey in Apps Script to invalidate the old key, then reconnect each device. Remove the web app deployment to stop access entirely. Offline workouts remain in local History and can be retried later.

Using another Sheet

A new independent Sheet needs its own bound script and deployment. Copying a Sheet also copies its bound script code, but set up the copy as a new connection: run rotateConnectorKey in the copy’s Apps Script project to ensure a fresh key, deploy its own Web App, and use that copy’s new URL and key. Do not reuse the old Sheet’s deployment details.
