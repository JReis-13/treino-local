One Google connector per account

Set up the standalone connector once. After that, import each training by pasting its normal Google Sheets URL. Start with a disposable Sheet copy.

  1. Open script.google.com and create a New project. Paste the complete v2 connector source into Code.gs.
  2. In Project Settings, show the appsscript.json manifest and replace it with this manifest. It requests only Google Sheets read/write scope.
  3. Run initializeConnector. Approve Google's spreadsheet permission prompt. Copy WORKOUT_CONNECTOR_KEY privately from Project Settings → Script Properties.
  4. Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Copy the /exec URL.
  5. In Treino Local → Plans, enter that URL and key under Google connection and connect. Then paste the normal URL of a Sheet copy and choose Import training.
Keep the deployment URL and key private. The script can open spreadsheets that its deploying Google account can access, but it acts only on IDs explicitly supplied and registered through the app. A stolen URL and key can register other accessible Sheets; rotate the key or disable the deployment if exposed. Each friend's device needs their own connector.

Existing bound connectors

Existing v1 plans continue working. Their connector is tied to one Sheet. You can keep it or import that Sheet again using v2 when ready.
